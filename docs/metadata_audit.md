# NIfTI 元数据审查约定

## 支持范围与来源

当前仅支持单文件 NIfTI-1 `.nii` / `.nii.gz`，标量 3D、大端/小端，已知空间单位米/毫米/微米。NIfTI-2、Analyze、分离 hdr/img、未知空间单位、4D、复数/RGB 数据等明确报错，不尝试猜测。

格式依据官方 [nifti1.h](https://github.com/NIFTI-Imaging/nifti_clib/blob/master/niftilib/nifti1.h)；四元数转换核对官方 [nifti1_io.c](https://github.com/NIFTI-Imaging/nifti_clib/blob/master/niftilib/nifti1_io.c)。实现限定为元数据审查，不替代未来正式医学影像读取/重采样库。

## 有界读取

每个选中的 CT 图像和标签只请求 352 字节解压头信息。gzip/文件缓冲可能预读少量压缩字节，但不主动遍历体素载荷或生成体素数组。读取前后核对文件大小和 mtime；保存头 SHA256，不计算完整体积文件哈希。

因此不能保证压缩文件尾部/CRC、体素载荷完整，不能确认强度范围、标签值域、图像标签内容对齐、器官出现或体积。合成测试特意使用没有体素载荷的头文件证明这一边界。

## 空间规则

- 有编码 sform 时优先使用，否则使用有编码 qform；两者均无编码时报错。无效的已声明变换报错，不静默回退。
- 同时存在时也计算 qform 与 sform 的角点差；超过统计配置容差报告警告。两者可能表达不同空间，该警告要求审查而不是自动修复。
- qform 的旋转、qfac 和偏移都参与换算。物理单位统一到 mm；仿射列向量长度是实际轴 spacing，与 pixdim 不同则警告。
- 配对检查原生数组 shape、spacing 和同一索引的世界坐标。检查体素单元边界八角点的最大欧氏距离，避免单轴长度 1 漏检；相同世界包围盒但数组翻转仍判不一致。
- 默认容差 0.001 mm 是元数据数值比较配置，不是重采样、小器官或分割性能阈值。误差原值写入 JSON。
- 原生 NIfTI i,j,k 轴不直接命名为 D,H,W。仅对轴对齐网格额外按 R/A/S 做尺寸/spacing 置换统计；不改变数据、不冻结后续模型方向。斜切/剪切标记警告，RAS 重排统计留空；仍保留世界边界包围盒。
- `cell_coverage=n*spacing` 表示体素单元边界覆盖长度，`center_span=(n-1)*spacing` 表示首末体素中心距离。两者并存防止 off-by-one，不替后续重采样网格约定做决定。

## 选择与报告

只读取 training 清单中配置范围内的 CT（默认编号 1–499）。其他训练条目只计数，不读取其 NIfTI。清单路径须在数据根内且分别位于 imagesTr/labelsTr；重复 ID/路径越界等拒绝运行。缺失 CT 文件和几何错误记录后继续其他病例；未列入清单的训练 NIfTI 报警告。

默认图像标签 sform/qform 编码不同并不直接视为错误；实际有效几何一致才通过。标签浮点类型或非单位缩放要求后续核查，但不检查标签体素值。

量化分布使用排序后线性插值分位数 `(n-1)*p`。代表病例分别按原体素数、物理覆盖体积、最大 spacing、最小 spacing、各向异性、最长覆盖轴选前五。它们不是最终重采样后的最大输入候选，也不能替代小器官筛选。

输出仅写入新的、位于数据目录外的报告目录；不覆盖历史结果。报告记录配置、清单/选中列表/头/代码哈希、Python、平台、Git commit 与 dirty 状态。病例级报告和数据根路径默认忽略，不随源码提交。
