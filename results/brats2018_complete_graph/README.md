# BraTS 2018 五折结果：完整方法（E1）与去掉关系推理（A3）

本目录是从 `runs/` 中已提交的日志导出的纯文本数据，用来分析一个问题：**为什么区域关系推理没有带来提升**。
数据由 `scripts/brats_export_results.py` 与 `scripts/brats_relation_probe.py` 生成，原始日志、checkpoint 与 MRI 不在仓库里。

## 1. 背景

- 任务：多模态 MRI（T1/T1ce/T2/FLAIR）脑肿瘤分割，三个相互嵌套、可重叠的区域 WT ⊇ TC ⊇ ET，各用独立 sigmoid。整脑一次前向，无 patch。
- 方法（公式级说明见仓库根目录 `METHOD_SPEC.md`，代码在 `src/organ_relation/models/`）：
  1. 双感受野编码器（4 级，32/64/128/256 通道）。
  2. 最深层 1×1 粗预测头给出三个区域的软掩码，按掩码把最深层特征池化成 WT/TC/ET 三个节点 z(0)，附带质心、体积、置信度（`space_to_node.py`）。
  3. **关系推理**（`dynamic_relation.py`）：三节点完全图、六条有向边、无自环；边权 α_ij = sigmoid(MLP([z_i; z_j; c_j − c_i; s_i; s_j; q_i; q_j]))，消息 m_j = Σ_i α_ij W_m z_i（求和），GRU 更新，K = 2 轮共享参数。
  4. 深层回写 F' = F + γ·φ(G)，G 为节点经注意力写回的内容，γ 初值 0.1（`node_to_space.py`、`residual_fusion.py`）。
  5. 解码器在三个跳连尺度上用 z(K) 做区域查询并回写：E' = E + η_l·Φ_l(G_l)，η 初值 1e-3；尺度权重由 z(K)、几何量和末轮入边权重经 MLP 得到（`brain_tumor.py`）。
  6. 损失：最终输出 BCE + Dice，加 0.5 × 粗预测 BCE + Dice，加 1.0 × 层级一致性项。
- **E1**：上述完整方法，配置 `configs/development/complete_graph/main.json`，8,387,120 参数。
- **A3**：同 E1，但不做关系推理：节点照常构建并用于回写和解码，z(K) = z(0)，尺度描述中的入边权重为 0。配置 `configs/development/complete_graph/no_relation.json`，7,894,255 参数。两者只差这一项。
- 协议（详见 `EXPERIMENTS.md` 第 1、2 节）：BraTS 2018 训练集 285 例，按患者五折（每折 228 训练 / 57 验证），整脑外接框裁剪，轻量增强（翻转 + 强度），AdamW 学习率 3e-4 全程固定，整网 bf16 混合精度，每轮在全部验证病例上评估；至少 20 轮，耐心 20 轮、min_delta 0.001 早停，上限 500 轮。验证集同时用于早停和选最佳轮，没有独立测试集。
- 计分：逐病例 hard Dice（阈值 0.5），病例内先平均三个区域再在病例间平均。真实与预测都为空的区域记为空、不计入；真实为空但预测非空记 0（与 BraTS 官方计分不同）。

## 2. 主要结果

| 折 | E1 最佳 Dice（轮） | A3 最佳 Dice（轮） | A3 − E1 |
| --- | --- | --- | ---: |
| 0 | 0.8017（81） | 0.8063（101） | +0.0046 |
| 1 | 0.7964（54） | 0.7918（70） | −0.0046 |
| 2 | 0.8140（65） | 0.8134（89） | −0.0006 |
| 3 | 0.8287（65） | 0.8300（49） | +0.0014 |
| 4 | 0.8302（68） | 未完成（第 4 轮中断） | — |
| 0–3 平均 | 0.8102 | 0.8104 | +0.0002 |

- 228 例病例配对（fold0–3，各取最佳轮）：A3 − E1 = +0.0002，95% 置信区间 [−0.006, +0.007]，t 检验 p = 0.95。WT、TC、ET 分别 +0.0005、−0.0058、+0.0018，均不显著。见 `comparisons.json`。
- 训练前期 E1 领先：前 10 轮 A3 比 E1 低约 0.01–0.02，约 30 轮后追平（可从 `epochs.csv` 复现）。
- 关系推理诊断（`relation_probe/`，fold0–1，CPU FP32 推理）：
  - 第 2 轮的边权在两折都被训练压到约 0.0003（未训练时约 0.5）；第 1 轮 fold0 约 0.002，fold1 约 0.98。
  - 推理时把全部边权置 0（保留 GRU）只降 0.0015 Dice，fold1 边全开也只降 0.002。z(K) 相对 z(0) 改变约 80%，几乎都来自 GRU 对节点自身的变换。
  - 推理时去掉深层回写（γ = 0）只降 0.003；去掉解码器回写（η = 0）E1 降 0.013、A3 降 0.033，节点信息主要经解码器回写起作用。
  - 详细数字见 `relation_probe/summary.txt` 与 `EXPERIMENTS.md` 5.4 节。

## 3. 文件与字段

所有表格以 `label`（E1 / A3）与 `fold`（0–4）标识运行；`epoch` 从 1 开始；Dice 为空表示该区域真实与预测都为空。

| 文件 | 内容 |
| --- | --- |
| `runs.csv` | 每个运行一行：目录名、训练代码提交号、变体、图结构、K、λ_hier、上限轮数、训练/验证病例数、实际轮数、状态（early_stopped / incomplete）、最佳轮与最佳 Dice（含三区域）、最后 5 轮平均、训练小时数（只含训练步） |

| `cases_epochs.csv` | 每个运行每轮每个验证病例一行：最终输出三区域 Dice、预测体素、真值体素、正确体素；粗预测三区域 Dice；ET 超出 TC 与 TC 超出 WT 的体素数；损失各项；软 Dice |
| `train_steps.csv.gz` | 每个训练步一行（gzip）：病例、损失各项、三区域软 Dice、学习率、步耗时、显存峰值、输入形状、增强参数（三轴翻转、各模态缩放与平移） |
| `comparisons.json` | A3 对 E1 的病例配对比较（fold0–3）：按折与合并，最佳轮与最后 5 轮平均两种口径，给出均值差、标准差、bootstrap 置信区间、t 检验与 Wilcoxon p 值、更好/更差病例数 |
| `relation_probe/probe_fold{0,1}.jsonl` | 关系推理探针逐例输出：首行为表头（checkpoint、代码版本），其后每行一个验证病例，含两种模型的回写占比、各轮边权与消息占比、各项推理时敲除后的 Dice。字段含义见 `scripts/brats_relation_probe.py` 的说明 |
| `relation_probe/summary.txt` | 上述探针结果的汇总（合并与逐折） |

## 4. 需要注意的地方

- 最佳轮与最后 5 轮平均通常相差 0.007–0.011，相邻两轮验证 Dice 常相差 0.005–0.02，比较差异小于约 0.01 时不能下结论。
- GPU 训练不是逐位确定的（同一代码两次运行在第 1 步就相差约 1e-6）。E1 与 A3 跑在不同提交上，但各版本间已用 CPU 训练场景验证计算逐值一致。
- ET 偏低主要来自无 ET 病例上的误报（见 `EXPERIMENTS.md` 4.3），与关系推理无关。
- 2026-11-10 起方法改为嵌套双向链 WT⇄TC⇄ET（四条边，向内、向外两类边分开设参），配置在 `configs/experiments/`，**尚未训练**，本目录不含它的结果。
